# 标题承诺与最低证据

这些是判断是否兑现承诺的规则，不是机械凑数要求。主题宇宙很小时可以减少候选，但必须解释覆盖范围。

## Best / Top / 年份榜单

需要：

- 多个具名、当前可验证的候选；通常至少 5 个，除非有效候选本来很少；
- 清楚的入选和排除方法；
- 同口径规格、价格和适用场景；
- 每个候选的优点、缺点和适用边界；
- 数据或测试日期；
- 如果没有第一手测试，明确说明证据来自何处，不能伪装实测。

只有一个无品牌商品或一组通用选购建议时，把标题改为 how-to。

## 品牌 Collection / 系列导购

需要：

- 多个官方确认的系列或产品线；
- 官方名称、版本、规格和差异；
- 当前商品与官方实体能一一对应；
- 真伪、授权、销售渠道和价格证据；
- 不能用“某品牌风格”“high version”或疑似仿品替代品牌商品。

## X vs Y

需要：

- X 和 Y 的同口径数据；
- 来源和采集日期；
- 关键差异为何影响选择；
- 按人群/场景给出选择结论；
- 明确何时两者都不适合。

## Fits / Measure / Size

需要：

- 用户应测量的字段和方法；
- 商品实际尺寸与允许误差；
- 障碍、净空、安装和退货条件；
- 至少一个能够完成匹配判断的商品，不能所有尺寸都写“去详情页确认”。

## Safe / Health / Beginner

需要：

- 权威来源和适当的专业审核；
- 清晰适用人群、禁忌、停止条件和替代方案；
- 不以简单自测代替诊断或专业许可；
- 不宣称绝对安全、治疗、预防或结果保证。

## Compatibility / Technical Specs

需要：

- 信号方向、协议、主机限制和设备端限制；
- 官方规格或标准来源；
- 同时说明“接口形状相同但功能不一定相同”的限制；
- 不把营销版本号等同于实际端到端能力；
- 产品卡必须具有决定兼容性的字段。

## Ethical / Authentic / Vegan / Cruelty-free

需要具体到品牌和产品的政策、认证或成分证据。品牌级口号不能自动覆盖所有 SKU；缺少验证时删除肯定性结论。
