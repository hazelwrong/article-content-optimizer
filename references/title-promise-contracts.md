# 按意图兑现内容承诺

先按 Query 与文章话题识别用户任务，再用以下要点找内容缺口。这些不是改变意图的路由，也不是固定商品数量、大纲或字数模板。一个商品链接不能证明文章是单品意图；没有价格或现成 SKU 不能成为改标题/改型的理由。

## Best / Top / 榜单

围绕文章限定的人群、用途、预算或场景研究适合候选，补清选择依据、关键差异、取舍与推荐理由。现有只挂一个商品时，按榜单意图补商品内容，不自动转 how-to。候选数取决于实际选择空间和覆盖需求；不为凑数引入不相关商品。

品牌候选应访问官方页面核实；无品牌类型推荐应明确是类型，不假装为具名实测单品。排名和“最佳”需有与意图一致的比较依据，不能仅因官网自称最好或 affiliate 可挂链就给最高推荐。涉及当前年份、价格或在售状态时核验对应时效，不自动给旧文换年份。

## 品牌 / Collection / 系列导购

根据 Query 和主题区分某型号、某系列、系列间比较或整个品牌范围，不能见到 collection 就固定要求多个系列。抓取品牌官网商品/系列/规格页面，补足用户任务需要的官方名称、版本、功能差异、适合人群和必要局限。

可以用品牌商品作为推荐并由团队后续挂 affiliate 链接。不要求先找到 marketplace 对应商品；不得把风格相似品冒充原品牌，也不得从允许 affiliate 推导“官方认证合作伙伴”等具体身份。

## X vs Y

研究两边的同口径事实，解释差异对实际使用的影响，并给出有依据的场景选择。缺少一侧就继续研究补齐，不把比较文变成只推荐资料更多的一侧。只补缺项，保留原文有效比较和例子。

## Fit / Measure / Size

补齐测量位置、方法、单位、净空、误差和匹配判断步骤。具体型号匹配需要官方尺寸与条件；通用测量意图可提供完整测量方法和选品条件，不强制插入具体商品。示例数字或计算必须明确是示例，不能伪装成实际商品规格。

## Compatibility / 技术规格

核实接口、信号方向、协议、设备端限制和实际功能；区分接口外形与功能能力、营销版本与端到端兼容性。可按需要补商品类型或官方品牌型号，不将缺商品链接写成正文障碍。

## How-to / 使用维护 / 知识解释

直接服务读者原有问题，补缺失的操作步骤、原因、例子、失败条件或适用范围。原文详细步骤和解释不能压缩成泛化清单。不强制把知识文的首屏改成“谁该买什么”，也不要求所有文章插商品。

## Safe / Health / Beginner

围绕原有主题补充有权威依据的适用条件、操作风险和必要停止条件。纠正具体不安全或无依据的说法，不能以通用免责声明掩盖它们，也不能因为涉及安全就将整篇转成另一主题。确需专业判断的个别结论单独标注，其他可靠内容继续优化。

## Authentic / Vegan / Cruelty-free 等品牌事实

访问品牌对应产品/政策及必要认证来源，核对适用对象、地区和版本。品牌级声明不能自动覆盖所有商品。无法确认的具体肯定性说法不得编造；在记录中说明检索范围及剩余疑点，继续完成可核实的内容。
