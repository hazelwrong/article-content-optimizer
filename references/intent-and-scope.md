# 意图、站点相关性与建议映射

## 唯一版本基线与目标市场

本项目以用户提供的HTML为唯一待改基线；URL用于绑定站点和文章及研究，不作为替代正文。多文件批量逐篇绑定URL、路径及hash，不混合版本；无HTML先补齐。所有原文片段和锚点来自该文件。用户另行提供新版本时，先确认对应文章并重新建立该篇对照，不套用旧偏移。

目标读者默认美国消费者、美元与美国购买渠道，同时服务加拿大、英国等英语国家；Query/话题明确地区时跟随该地区。新增/替换的读者正文使用英语。结合输入明确本篇国家或地区，按需要核实当地单位、标准、尺码和购买条件，不凭英语语言推断所有国家规则一致。若待改稿本身非英语，原文列仍逐字保留；明确局部修改与整篇英语交付之间的范围冲突，不自行全篇翻译或重写。

## 六站相关性

本项目六站含 Fashion、Sports、Tech、Beauty、Home & Garden、Lifestyle；用户所说“五站”同样按六站理解。优先使用本次提供的站点定位/类目规则；没有更具体规则时，用以下主题边界判断，不因旧资料曾写 Lifestyle 暂缓扩张就排除它。

| 站点 | 核心相关方向 |
|---|---|
| Fashion / fashion.dhgate.com | 服饰、鞋包、配饰、穿搭、材质、尺码及护理 |
| Sports / sports.dhgate.com | 运动参与、训练、装备选择与使用、运动场景需求 |
| Tech / tech.dhgate.com | 消费电子、设备与配件、功能、兼容性和使用问题 |
| Beauty / beauty.dhgate.com | 美妆、护肤、头发、美甲、工具和相关产品使用 |
| Home & Garden / homegarden.dhgate.com | 家居、收纳、清洁、家具、装饰、园艺和维护 |
| Lifestyle / lifestyle.dhgate.com | 生活方式、日常生活场景与实用需求；需有明确受众和生活任务，不能兜底所有新闻 |

判断主问题和读者预期，不只匹配名词。明星穿搭的服装特点/搭配分析可与 Fashion 相关；仅讲明星感情八卦不能因出现衣服就算相关。运动装备使用指南与 Sports 相关，纯比赛比分报道不因提及运动就自动相关。技术发布若实质解释功能、兼容性或用户影响可相关；纯公司股价新闻不能硬加配件段落过关。

- **相关**：能说明该站读者为什么需要这篇文章，继续优化。信息解释、使用和维护也可相关，不要求每篇都带商品。
- **不相关**：与站点任务无实质联系，记录原因后提前结束；不检索大量资料、不改写成导购、不继续技术扫描。仍按三 Sheet 输出结果。
- **待确认**：归属或话题确有歧义，写明依据与缺失信息；不要猜成“不相关”。跨站重叠不代表全矩阵无关，也不自动迁站，记录所属站点疑点。

## Query 用于理解，不用于机械植词

1. 读取全部提供的 Query 及可用的点击、曝光、排名、地区和时间范围；没有指标时不能臆造权重。
2. 在分析层归并明显错拼、大小写、同义表达与语序变化；保留语义不同的意图。含糊错拼不强行猜测。
3. 区分主任务、支持该任务的次问题、偶发/无关流量。结合语义和原文判断，不按单个高曝光词直接更换主题。
4. 对照原文的标题、首屏、章节、详细论述和用户可完成的动作；标题可能失真，不能只看标题。
5. 用自然语言写出一句主意图和必要的次意图，记录依据。Query 不作为必须逐字写入文章的关键词列表；正确的自然表达可以正常出现。

无 Query 时以文章本身的话题和任务为基线。现有商品数量、模块缺失和能否立即找到商品链接都不能替代意图判断。

若 Query 与文章话题支持同一任务，围绕该任务补内容。若 Query 呈现明确不同任务，或标题与正文严重分裂，记录冲突及可能解释，只就方向性选择请求确认；继续处理事实纠错、泄漏删除等不依赖方向的独立问题。不要擅自选高流量任务、较易写的任务或资料更全的任务。

## 原文保护与建议覆盖

先保存原文基线及以下简短记录，放 Sheet1 顶部摘要区：基线版本及选择依据、目标市场/正文英语、站点相关性、受众/主意图/必要次意图、判断依据和范围、Query 是否提供。无需另做评分报告。

通读全部建议后，将每条映射为具体位置与动作；一个建议可对应多个修改项，也可只对应一句新增或一段删除。重复建议可合并引用，但不遗漏处理结果。

- 原文已满足：说明所在位置，不为展示工作量重复修改。
- 建议与意图/有效细节冲突：解释冲突，标记待确认或有依据地不采用，不能默默忽略。
- 用户明确限定修改范围：只执行该范围，其他观察放备注；宽泛请求则可继续发现并修复其他低质量内容。
- 局部模式中不涉及的有效内容保持原样；重构模式允许迁移组织，但逐项保留正确步骤、数值、例子、比较和条件。确需删改须对应明确问题。保护信息不等于保护原句。全文审核独立于手工建议和编辑权限，范围外问题仍记录。

最终逐条核对建议是否有结果，再把变更放回全文检查衔接。信息增量是解决缺口，不能以补内容为由引入另一篇文章的主任务。
