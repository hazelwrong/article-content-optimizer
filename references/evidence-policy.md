# 证据与来源政策

## 通用优先级

1. 官方品牌、制造商、标准组织、监管机构；
2. 大学、医疗机构、专业协会、公开研究；
3. 有透明测试方法的专业媒体或实验室；
4. 当前商品页和可追溯的内部数据；
5. 论坛、社区和评论，只用于发现用户问题或汇总体验，不单独支撑安全、规格或品牌事实。

记录来源 URL、支持的具体论断和采集日期。来源存在不等于已支撑论断；必须检查页面是否真的包含对应信息。

当原稿和现有资料不足以形成中等以上信息增量时，应主动检索相关网页。检索必须围绕用户当前任务，优先补充可执行方法、统一比较维度、适用场景、边界、反例、停止条件和能降低决策成本的权威数据。不要为了显得研究充分而堆砌弱相关链接。

## 商品与品牌

- 商品标题不是可靠的官方规格来源，尤其是拼写异常、容量异常、`style`、`inspired`、`high version` 或品牌字段缺失时。
- 将 marketplace 商品映射到品牌系列前，必须核对官方名称、包装、容量和卖家身份。
- 价格、库存、评分、评论量、运输和退货是动态数据，必须带日期。

## 技术

优先标准组织、芯片/设备制造商和操作系统官方文档。社区问答可作为故障线索，不能覆盖协议、带宽和兼容性结论。

## 健康、运动和安全

优先监管机构、医疗机构和专业协会。一般免责声明不能补救错误的动作、安全、过敏、孕期或疾病建议。需要专业审核时，在交付中明确 reviewer 要求，不虚构审核已经完成。

## 家居安装与材料

尺寸、承重、防倾倒、电气、湿度和材料耐久结论应使用产品说明、制造商资料、标准或政府安全资源。论坛经验只能补充常见故障模式。

## 第一手体验

只有确实执行过测试并掌握记录时才能写第一人称体验。否则说明分析基于官方规格、商品数据、评论样本或第三方测试，并披露局限。

## 研究方法与价值表达

文章末尾的证据说明应优先体现实际研究过程和读者价值，而不是用大段否定式免责声明削弱文章：

- 说明实际审阅的资料类型，例如制造商尺寸页、安装说明、标准、政府指南、公开研究或可追溯商品数据；
- 说明如何核对，例如统一测量字段、交叉比较多个一级来源、区分通用规则与型号特定要求；
- 说明产出价值，例如把分散资料整理成测量流程、筛选框架、检查清单或停止条件；
- 只有来源账本真实记录了数量时，才可以写“审阅了 X 份资料”“进行了 X 轮搜索”或具体样本数；
- 只有真实做过并保留记录时，才可以写“我们测试了”“我们实测”或“最好用”；否则使用“研究汇总”“基于公开证据整理”“实用方法”等准确表述；
- 安全、法规、安装条件、动态规格等必要限制仍要保留，但应简短、具体并放在相关结论附近，不把整段结尾写成自我否定。

可用的英文表达方向：`How we researched this guide`、`How we built this method` 或 `Why this approach is useful`。正文只能陈述本次来源账本能够证明的研究动作和价值。
